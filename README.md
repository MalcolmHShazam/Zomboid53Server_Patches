# Zomboid53Server_Patches

Custom patches for mods for multiplayer server.

## How to join

1. Open the [Steam Workshop collection](https://steamcommunity.com/sharedfiles/filedetails/?id=3827405167) and click **Subscribe to all**. Let Steam finish downloading everything.
2. Download and run [ZomboidPatches.bat](https://github.com/MalcolmHShazam/Zomboid53Server_Patches/raw/main/ZomboidPatches.bat). It installs or updates the patched mods below in your `Zomboid\mods` folder. Run it again whenever the patches change.
3. Start Project Zomboid and join the server.

Collection: https://steamcommunity.com/sharedfiles/filedetails/?id=3827405167
